# Norn-StockScreener (Fork)

A personal US stock factor screening dashboard. Forked from
[zmcx16/Norn-StockScreener](https://github.com/zmcx16/Norn-StockScreener) and
rebuilt to run fully self-contained on free infrastructure.

**Live site:** https://brickerp.github.io/Norn-StockScreener/

## What changed vs upstream

The upstream project depends on the author's private backend APIs
(`AF_URL`/`MARKET_URL` secrets) for both data fetching and the search/filter
engine. This fork removes those dependencies:

| Layer | Upstream (private) | This fork |
|---|---|---|
| Data source | Private `get-stock-report` API | **yfinance** (`Ticker.info`) — free, no key |
| Factor data | `stat.json` written by backend | Same `stat.json` schema, generated by our own script |
| Query engine | POST to `do-norn-screen` API | **Pure front-end** filtering (`src/common/queryStocks.js`) |
| Universe | Private stock list | S&P500 (503 symbols, `static/stock_symbols.txt`) |
| Deploy | Manual build + push | **GitHub Actions** (daily cron → build → gh-pages) |

## Features

- 58 filter criteria (P/E, PEG, ROE, ROA, ROI, P/FCF, Debt/Eq, margins,
  performance, SMA, etc.) — same UI as upstream
- Sector / industry filtering
- Multi-factor ranking (weighted z-score)
- Simplified risk score (replaces the upstream NornMinehunter engine)
- Sortable DataGrid with Finviz / Yahoo links

### Factors computed from yfinance

| Stat.json field | Source |
|---|---|
| `PEG`, `P/E`, `Forward P/E`, `P/B`, `P/S` | `Ticker.info` (`pegRatio`, `trailingPE`, ...) |
| `ROE`, `ROA`, `ROI`, margins, ratios | `Ticker.info` (`returnOnEquity`, `grossMargins`, ...) |
| `Market Cap`, `Close`, 52W High/Low | `Ticker.info` / `history()` |
| `P/FCF` | `freeCashflow` / shares outstanding |
| `Perf Week/Month/Quarter/Half Y/Year/YTD`, `SMA20/50/200` | computed from 1y `history()` |
| `sector` / `industry` | `Ticker.info` mapped to upstream index dicts |

## Data pipeline

```
GitHub Actions (daily 02:10 UTC, or manual dispatch)
  → fetch_stock_data.py
      yfinance Ticker.info + 1y history for 503 S&P500 stocks
      → static/stat.json
  → npm install --legacy-peer-deps
  → gatsby build --prefix-paths
  → peaceiris/actions-gh-pages → gh-pages branch
```

GitHub Pages serves `https://<user>.github.io/Norn-StockScreener/`.

## Local development

Requires Node 16/18 (Gatsby 2.x).

```bash
npm install --legacy-peer-deps
npm run develop   # http://localhost:5000
```

To regenerate data locally:

```bash
pip install -r .github/fetch_stock_data/requirements.txt
python .github/fetch_stock_data/fetch_stock_data.py
```
