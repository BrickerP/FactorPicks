# Norn-StockScreener (Fork)

A personal US stock factor ranking dashboard. Forked from
[zmcx16/Norn-StockScreener](https://github.com/zmcx16/Norn-StockScreener) and
rebuilt as a minimal single-table UI on free infrastructure.

**Live site:** https://brickerp.github.io/Norn-StockScreener/

## What changed vs upstream

| Layer | Upstream (private) | This fork |
|---|---|---|
| Data source | Private `get-stock-report` API | **yfinance** (`Ticker.info`) — free, no key |
| Factor data | `stat.json` written by backend | Same `stat.json` schema, generated by our own script |
| Query engine | POST to `do-norn-screen` API | **Pure front-end** filtering (`src/lib/queryStocks.js`) |
| Universe | Private stock list | S&P500 (503 symbols, `public/stock_symbols.txt`) |
| UI | MUI DataGrid + 58 filter criteria | **Vite + React, minimal single table** |
| Deploy | Manual build + push | **GitHub Actions** (daily cron → build → gh-pages) |

## Features

- Core ranking columns: Symbol, Name, Market Cap, P/E, PEG, FCFF/EV, ROE, Rank
- Click any column header to sort
- Multi-factor weighted z-score ranking (ROE / PEG / FCFF/EV presets)
- Watchlist mode (default) or all S&P500 stocks
- Fully self-contained: no backend, no API keys

## Data pipeline

```
GitHub Actions (daily 02:10 UTC, or manual dispatch)
  → fetch_stock_data.py
      yfinance Ticker.info + 1y history for 503 S&P500 stocks
      → public/stat.json
  → npm install
  → vite build
  → peaceiris/actions-gh-pages → gh-pages branch
```

## Local development

```bash
npm install
npm run dev   # http://localhost:5173
```

To regenerate data locally:

```bash
pip install -r .github/fetch_stock_data/requirements.txt
python .github/fetch_stock_data/fetch_stock_data.py
```
